# Crisp Career Gate

**Crisp Career Gate** replaces boring job offer texts with an interactive, secure digital envelope reveal. Transform standard hiring notifications into an exciting, memorable onboarding experience for modern HR teams. Fast, clean, and unforgettable.

## ✨ Features
- **Secure Envelope Reveal:** Candidates must enter their name or an access code to unlock their offer.
- **Modern Dark Aesthetic:** Clean UI designed to match the professional Crisp Suite look.
- **Zero Backend Required:** Pure HTML, CSS, and JavaScript—lightweight and blazing fast.
- **Plug-and-Play:** Ready to deploy instantly on GitHub Pages and link to Gumroad.

## 🚀 Quick Start
1. Clone or download this repository.
2. Update your custom welcome message and access requirements in `index.html`.
3. Enable GitHub Pages in your repository settings to launch the live preview.
